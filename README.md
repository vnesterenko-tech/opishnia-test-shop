# Тестовий магазин для задачі 24253 «Автооновлення каталогу»

Сайт: https://vnesterenko-tech.github.io/

Усі дані товарів лежать в одному файлі **`products.csv`**. Після кожного коміту GitHub Actions
запускає `build.py`, який збирає статичні HTML-сторінки з JSON-LD і публікує їх на Pages (1–2 хв).
Прогрес і помилки — вкладка **Actions**.

## Як міняти товари

Відкрийте `products.csv` → олівець (Edit) → змініть → **Commit changes**. GitHub показує CSV таблицею, редагувати можна прямо в браузері або в Excel/Google Sheets (зберегти як CSV UTF-8).

| Колонка | Що це | Приклад |
|---|---|---|
| `sku` | артикул, обов'язковий і унікальний; з нього будується адреса `product/<sku>.html` | `OP-002` |
| `name` | назва, обов'язкова | `Макітра 3 л` |
| `category` | категорія; нова назва — нова категорія в меню | `Декор` |
| `price` | ціна, обов'язкова | `950` |
| `old_price` | стара ціна; знижка % рахується сама | `1390` |
| `qty` | кількість (правило 1). Порожньо = кількості на сайті немає | `5`, `0` |
| `status` | статус без кількості (правило 2): `В наявності`, `Немає в наявності`, `Під замовлення`, `Очікується` | `Під замовлення` |
| `delivery_days` | термін доставки, днів | `14` |
| `description` | опис; якщо є кома — у лапках | `"Опис, з комою"` |

Правила наявності (як у ТЗ):
1. Заповнено `qty` → на сторінці «В наявності: N шт.» або «Немає в наявності (0 шт.)», у JSON-LD `inventoryLevel` + `availability`. `status` тоді ігнорується.
2. `qty` порожнє, заповнено `status` → лише статус.
3. Обидва порожні → рядка наявності немає взагалі.

Додати товар — новий рядок. Прибрати товар із сайту — видалити рядок. Головна, категорії і `sitemap.xml` перебудуються самі.

Якщо в CSV помилка (невідомий статус, текст замість ціни, повтор артикула), збірка в Actions стане червоною з номером рядка, а сайт лишиться попередньої версії.

## Сценарій «оновлення» для чекліста

| Що змінити в CSV | Очікування в каталозі після оновлення |
|---|---|
| OP-001: `price` 680 → 720 | нова ціна, бот каже 720 |
| OP-002: `qty` 5 → 0 | in_stock = false, stock_quantity = 0 |
| OP-003: змінити `description` | ручний опис у кабінеті лишився |
| OP-014: `status` В наявності → Немає в наявності | in_stock = false |
| Видалити рядок OP-007 | запис лишився, in_stock = false, «не знайдено на сайті» |
| Додати рядок `OP-021,Макітерка мала 1 л,Посуд для готування,430,,8,,,Мала макітра для соусів.` | новий товар з approved = false |
| Лишити 5 рядків із 20 | запуск відхилено (менше половини), каталог без змін |

## Службове

- `build.py` — генератор (лише стандартний Python). Локально: `python build.py`, результат у `_site/`.
- `.github/workflows/pages.yml` — збірка і публікація.
- `style.css` — стилі.
- Старі папки `product/`, `category/`, `img/`, `zapas/` і HTML у корені більше не використовуються (публікується лише `_site`), їх можна видалити.
